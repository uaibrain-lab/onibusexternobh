# Avisos de atribuição

## Layout e padrões de interação do Hub UFMG / Interno

A aparência e os padrões de interação do protótipo Externo foram adaptados da aba Interno de `uaibrain-lab/ru-hoje`, cujo HTML contém atribuição ao projeto `internorotas/ufmg` para dados, linhas/paradas e lógica de horários. Nenhum dado original do Interno foi incorporado ao rastreador Externo; este utiliza o GTFS de BH.
